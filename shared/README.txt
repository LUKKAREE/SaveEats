================================================================================
                    shared/ - Type กลางของ SaveEats
================================================================================

โฟลเดอร์นี้เก็บ "รูปแบบข้อมูล" ที่ทั้ง 3 ฝั่งใช้ร่วมกัน
      backend/  <->  shared/  <->  mobile/  และ  admin-web/

*** นี่คือหัวใจของการเปลี่ยนมาใช้ TypeScript ***
กฎเหล็กข้อ 5 บอกว่า "ตั้งชื่อ field ให้ตรงกันทั้ง 3 ฝั่ง"
เดิมต้องอาศัยความจำและวินัยของคนเขียน
ตอนนี้ถ้าชื่อไม่ตรง TypeScript จะฟ้องทันทีตั้งแต่ตอนพิมพ์ ไม่ต้องรอรันโปรแกรม

ไฟล์ในโฟลเดอร์นี้
-----------------
  src/enums.ts       ค่าคงที่ที่เป็นชุดตัวเลือก เช่น role, สถานะการจอง, สถานะร้าน
                     *** ค่าต้องตรงกับ ENUM ใน database/schema.sql เป๊ะ ***

  src/entities.ts    หน้าตาของข้อมูลแต่ละตาราง (User, Store, Food, Post, ...)
                     *** ชื่อ field ต้องตรงกับคอลัมน์ใน schema.sql เป๊ะ ***

  src/dto.ts         หน้าตาข้อมูลที่ "ส่งเข้า" API เช่น ฟอร์มสมัครสมาชิก

  src/api.ts         หน้าตาข้อมูลที่ API "ส่งกลับ" เช่น ApiResponse, FeedItem

  src/labels.ts      ข้อความภาษาไทยของแต่ละสถานะ ใช้ร่วมกันทั้งแอปและเว็บ
                     จะได้ไม่เกิดกรณีแอปเขียน "รับแล้ว" แต่เว็บเขียน "สำเร็จ"

  src/index.ts       รวม export ทุกอย่างไว้ที่เดียว

วิธีเรียกใช้ (เหมือนกันทั้ง 3 โปรเจกต์)
--------------------------------------
      import type { Post, Reservation } from '@shared/index';
      import { ReservationStatus } from '@shared/index';

*** ไม่ต้อง build โฟลเดอร์นี้ ***
ทั้ง 3 โปรเจกต์อ่านไฟล์ .ts ตรง ๆ ผ่านการตั้ง path alias ไว้แล้ว
      backend    ตั้งใน tsconfig.json (tsx อ่าน paths ให้เอง)
      admin-web  ตั้งใน vite.config.ts (resolve.alias)
      mobile     ตั้งใน babel.config.js + metro.config.js

ถ้าแก้ไฟล์ในโฟลเดอร์นี้
-----------------------
  1. ต้องแก้ database/schema.sql ให้ตรงกันด้วยเสมอ
  2. รัน npm run typecheck ในแต่ละโปรเจกต์ เพื่อดูว่ามีที่ไหนพังบ้าง
     TypeScript จะชี้ให้เห็นทุกจุดที่ต้องตามไปแก้
