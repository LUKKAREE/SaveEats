โฟลเดอร์นี้ว่างแล้ว - ย้ายไป shared/ ทั้งหมด
============================================

เดิม (ตอนใช้ JavaScript)
  mobile/src/models/  เก็บ JSDoc อธิบายหน้าตาข้อมูลที่รับมาจาก Backend
  backend/src/models/ เก็บโค้ด SQL
  แล้วต้องคอยดูแลให้ชื่อ field ตรงกันเองด้วยความจำและวินัย

ตอนนี้ (ใช้ TypeScript)
  หน้าตาข้อมูลทั้งหมดย้ายไปอยู่ที่  shared/src/entities.ts
  ทั้ง backend และ mobile ใช้ type ตัวเดียวกัน
  ถ้าชื่อ field ไม่ตรง TypeScript จะฟ้องทันทีตั้งแต่ตอนพิมพ์

วิธีเรียกใช้
  import type { Post, Reservation, Store } from '@shared/index';

*** backend/src/models/ ยังอยู่เหมือนเดิม ***
เพราะเป็นที่เก็บโค้ด SQL ซึ่งเป็นคนละเรื่องกับ "หน้าตาข้อมูล"

โฟลเดอร์นี้เก็บไว้เพื่อให้โครงตรงกับเอกสารแผนงานเดิม
ถ้าไม่ต้องการแล้วลบทิ้งได้เลย
