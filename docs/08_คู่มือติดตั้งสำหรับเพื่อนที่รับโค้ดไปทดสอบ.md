# SaveEats — คู่มือติดตั้งและรัน (สำหรับคนที่เพิ่งได้โค้ดไป)

อ่านจบแล้วรันได้เลย ไม่ต้องมีความรู้เรื่องระบบนี้มาก่อน
ใช้เวลาประมาณ **20–30 นาที** ถ้าเครื่องยังไม่เคยลงอะไรเลย

ระบบนี้มี 3 ส่วนที่ต้องเปิดพร้อมกัน

| ส่วน | คืออะไร | เปิดยังไง |
|---|---|---|
| **Backend** | ตัวกลางที่คุยกับฐานข้อมูล | หน้าต่าง cmd ที่ 1 |
| **แอปมือถือ** | ฝั่งลูกค้ากับร้านค้า | หน้าต่าง cmd ที่ 2 + มือถือ |
| **หน้า Admin** | เว็บผู้ดูแลระบบ | หน้าต่าง cmd ที่ 3 + เบราว์เซอร์ |

> **หน้าต่าง cmd ทั้ง 3 ต้องเปิดค้างไว้ตลอดเวลาที่ทดสอบ** ปิดอันไหนอันนั้นก็หยุดทำงาน

## ขั้นที่ 0 — ลงโปรแกรมที่ต้องมีก่อน

| โปรแกรม | เอาไว้ทำอะไร | โหลดที่ไหน |
|---|---|---|
| **Node.js เวอร์ชัน 20 ขึ้นไป** | รันโค้ดทั้งหมด | https://nodejs.org (เลือก LTS) |
| **XAMPP** | ฐานข้อมูล MySQL + phpMyAdmin | https://www.apachefriends.org |
| **Expo Go** | เปิดแอปบนมือถือ | App Store / Play Store |

เช็คว่า Node ลงสำเร็จแล้ว เปิด cmd พิมพ์

```
node -v
```

ต้องขึ้นเลข **v20** ขึ้นไป (เช่น v22.14.0) ถ้าขึ้น v18 หรือต่ำกว่า ให้ลง Node ใหม่ ไม่งั้นแอปมือถือจะรันไม่ผ่าน

**มือถือกับคอมต้องต่อ Wi-Fi วงเดียวกัน** — ข้อนี้สำคัญมาก ถ้าคอมต่อ LAN แล้วมือถือต่อ Wi-Fi คนละวง จะเปิดแอปไม่ได้เลย

## ขั้นที่ 1 — แตกไฟล์

แตกไฟล์ ZIP ไว้ที่ไหนก็ได้ที่ **path ไม่มีภาษาไทยและไม่มีเว้นวรรค**

- ดี : `C:\SaveEats`
- ใช้ได้ : `C:\Users\ชื่อคุณ\Desktop\SaveEats`
- **หลีกเลี่ยง** : path ที่มีวงเล็บหรืออักษรไทย เพราะบางคำสั่งจะพังแบบไม่บอกสาเหตุ

ในโฟลเดอร์ต้องเห็น `backend` `mobile` `admin-web` `shared` `database` `docs` ครบ

ต่อจากนี้จะเรียกโฟลเดอร์นี้ว่า **โฟลเดอร์หลัก**

## ขั้นที่ 2 — ติดตั้งไลบรารี

ใน ZIP ไม่มีโฟลเดอร์ `node_modules` มาให้ (ใหญ่เกินไป) ต้องสั่งโหลดเอง

เปิด cmd แล้วพิมพ์ทีละบล็อก **รอให้เสร็จก่อนค่อยขึ้นบล็อกถัดไป** แต่ละอันใช้เวลา 1–3 นาที

```
cd C:\SaveEats\backend
npm install
```

```
cd C:\SaveEats\mobile
npm install
```

```
cd C:\SaveEats\admin-web
npm install
```

> โฟลเดอร์ `shared` ไม่ต้องติดตั้งอะไร มันเป็นแค่ไฟล์โค้ดที่อีก 3 ส่วนใช้ร่วมกัน
>
> ถ้าเจอคำเตือนสีเหลือง `npm warn deprecated ...` **ไม่ต้องสนใจ** ไม่ใช่ error
> ถ้าเจอสีแดงคำว่า `npm error` ให้ดูหัวข้อ "ปัญหาที่เจอบ่อย" ท้ายคู่มือ

## ขั้นที่ 3 — สร้างฐานข้อมูล

**3.1** เปิด **XAMPP Control Panel** กด **Start** ที่ `Apache` และ `MySQL` ให้ขึ้นแถบเขียวทั้งคู่

**3.2** เปิดเบราว์เซอร์ไปที่ http://localhost/phpmyadmin

**3.3** ดูมุมบนของหน้า จะเห็นข้อความประมาณ `Server: 127.0.0.1:3306`

**จดเลขพอร์ตนี้ไว้** (3306 หรือ 3307) เดี๋ยวต้องใช้ในขั้นที่ 4 — เครื่องแต่ละคนไม่เหมือนกัน

**3.4** คลิกแท็บ **Import** ด้านบน (ยังไม่ต้องเลือกฐานข้อมูลไหน)

กด **Choose File** เลือกไฟล์ `database\schema.sql` แล้วกด **Go** ล่างสุด

รอจนขึ้นข้อความเขียว จะเห็นฐานข้อมูลชื่อ `saveeats` โผล่มาทางซ้าย

**3.5** **คลิกที่ชื่อ `saveeats` ทางซ้ายก่อน** แล้วค่อยคลิกแท็บ **Import** อีกครั้ง

คราวนี้เลือกไฟล์ `database\seed.sql` แล้วกด **Go**

> ขั้นตอน 3.5 ที่ต้องคลิกชื่อฐานข้อมูลก่อนสำคัญมาก ถ้าลืมคลิก ข้อมูลจะไปลงผิดที่แล้วขึ้น error

**3.6** เช็คว่าสำเร็จ — คลิก `saveeats` ทางซ้าย ต้องเห็นตาราง 11 ตาราง (`users`, `stores`, `posts`, `reservations`, ...) และตาราง `users` ต้องมีข้อมูลอยู่

## ขั้นที่ 4 — ตั้งค่า Backend

**4.1** เข้าโฟลเดอร์ `backend` จะเห็นไฟล์ชื่อ `.env.example`

ก็อปเป็นไฟล์ใหม่ชื่อ `.env` — เปิด cmd พิมพ์

```
cd C:\SaveEats\backend
copy .env.example .env
```

**4.2** เปิดไฟล์ `backend\.env` ด้วย Notepad หรือ VS Code

หาบรรทัด `DB_PORT` แล้ว **แก้ให้ตรงกับเลขที่จดไว้ในขั้น 3.3**

```
DB_PORT=3306
```

> จุดนี้คือสาเหตุอันดับหนึ่งที่ backend เปิดไม่ขึ้น
> XAMPP บางเครื่องใช้ 3306 บางเครื่อง 3307 ต้องดูของตัวเองเท่านั้น ห้ามเดา

ค่าอื่นในไฟล์ปล่อยไว้ก่อนได้ทั้งหมด

## ขั้นที่ 5 — หาเลข IP ของคอม แล้วแก้ 2 จุด

มือถือเรียก `localhost` ของคอมไม่ได้ เพราะคำว่า localhost บนมือถือหมายถึงตัวมือถือเอง
ต้องบอกเลข IP จริงของคอมให้แอปรู้

**5.1** เปิด cmd พิมพ์

```
ipconfig
```

มองหาบรรทัด **IPv4 Address** จะได้เลขประมาณ `192.168.1.35`

> ถ้ามีหลายอัน ให้เอาอันที่อยู่ใต้หัวข้อ **Wireless LAN adapter Wi-Fi**
> **อย่าเอาเลขที่ขึ้นต้นด้วย 26.x** (Radmin VPN) หรือ **172.x** (VirtualBox) จะใช้ไม่ได้

**5.2** เปิดไฟล์ `mobile\src\core\constants\apiConstants.ts`

หาบรรทัดที่เขียนว่า `<<<< แก้เลข IP ตรงนี้ >>>>` แล้วเปลี่ยนเลขให้เป็นของคุณ

```ts
const DEV_HOST = '192.168.1.35';
```

**5.3** เปิดไฟล์ `backend\.env` อีกครั้ง แก้บรรทัด `PUBLIC_BASE_URL` ให้ใช้เลขเดียวกัน

```
PUBLIC_BASE_URL=http://192.168.1.35:3000
```

> ถ้าข้ามข้อ 5.3 แอปจะใช้งานได้ปกติ แต่**รูปอาหารกับรูปร้านจะไม่ขึ้นบนมือถือ**
> เพราะรูปยังชี้ไปที่ localhost อยู่

> **IP เปลี่ยนทุกครั้งที่ย้ายที่หรือเปลี่ยน Wi-Fi** ต้องกลับมาแก้ 2 จุดนี้ใหม่เสมอ

## ขั้นที่ 6 — รันทั้ง 3 ส่วน

เปิด cmd **3 หน้าต่างแยกกัน** แล้วเปิดค้างไว้ทั้งหมด

### หน้าต่างที่ 1 — Backend

```
cd C:\SaveEats\backend
npm run dev
```

**สำเร็จเมื่อ** เห็นข้อความ

```
สถานะ  : ทำงานอยู่
Port    : 3000
```

**ถ้าขึ้น** `!! เชื่อมต่อฐานข้อมูลไม่สำเร็จ` แปลว่า MySQL ไม่ได้เปิด หรือ `DB_PORT` ในขั้น 4.2 ผิด

**เช็คเพิ่ม** เปิดเบราว์เซอร์บนคอมไปที่ http://localhost:3000/api/health ต้องเห็นข้อความ JSON

### หน้าต่างที่ 2 — แอปมือถือ

```
cd C:\SaveEats\mobile
npx expo start
```

**สำเร็จเมื่อ** เห็น QR code ขึ้นมาและเคอร์เซอร์ค้างรออยู่ (ไม่เด้งกลับไปที่ `C:\...>`)

ดูบรรทัดที่ขึ้นต้นด้วย `exp://` ต้องเป็นเลข IP เดียวกับที่ใส่ในขั้น 5.2

### หน้าต่างที่ 3 — หน้า Admin

```
cd C:\SaveEats\admin-web
npm run dev
```

**สำเร็จเมื่อ** เห็นข้อความ `Local: http://localhost:5173/`

เปิดเบราว์เซอร์ไปที่ http://localhost:5173

## ขั้นที่ 7 — เปิดแอปบนมือถือ

1. เปิดแอป **Expo Go**

## บัญชีทดสอบ

**รหัสผ่านทุกบัญชีคือ `123456`**

| ใช้ทดสอบอะไร | อีเมล | เข้าที่ไหน |
|---|---|---|
| ผู้ดูแลระบบ | `admin@saveeats.com` | หน้า Admin (เบราว์เซอร์) |
| ลูกค้า มีประวัติจอง + รีวิวแล้ว | `customer1@test.com` | แอปมือถือ |
| ลูกค้า มีการจองที่ยังไม่ได้รับ (ใช้ทดสอบสแกน QR) | `customer2@test.com` | แอปมือถือ |
| ร้านค้าที่อนุมัติแล้ว มีของขาย | `seller1@test.com` | แอปมือถือ |
| ร้านที่รออนุมัติ (ใช้ทดสอบหน้าอนุมัติของ Admin) | `seller4@test.com` | แอปมือถือ |

### แนวทางทดสอบเร็ว ๆ

1. ล็อกอินเป็น `customer1@test.com` ในแอป → เลือกอาหาร → กดจอง → จะได้ QR code
2. ออกจากระบบ ล็อกอินเป็น `seller1@test.com` → เข้าเมนูสแกน QR → สแกนของลูกค้า → จำนวนอาหารต้องลดลง
3. เปิดหน้า Admin ในเบราว์เซอร์ → เมนู "การจอง" → ต้องเห็นรายการที่เพิ่งทำ

## ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| `!! เชื่อมต่อฐานข้อมูลไม่สำเร็จ` | MySQL ไม่ได้เปิด หรือพอร์ตผิด | เปิด MySQL ใน XAMPP และเช็ค `DB_PORT` ในขั้น 4.2 |
| กด `npx expo start` แล้วเด้งกลับทันที ไม่มี QR | เน็ตมีปัญหาตอนเช็คเวอร์ชัน | ลอง `npx expo start --offline` ถ้ายังไม่ได้ลอง `npx expo start --port 8082` |
| แอปเปิดได้ แต่หน้าแรกว่างเปล่า / โหลดค้าง | มือถือคุยกับ backend ไม่ได้ | เปิดเบราว์เซอร์**บนมือถือ** ไปที่ `http://<IP>:3000/api/health` ถ้าไม่ขึ้น = IP ผิด หรือ Firewall บล็อก |
| เปิด `/api/health` บนมือถือไม่ขึ้นทั้งที่ IP ถูก | Windows Firewall บล็อกพอร์ต 3000 | Windows Security → Firewall → Allow an app → อนุญาต Node.js ทั้ง Private และ Public |
| หน้าแผนที่เป็นจอเทา | ยังไม่ได้ใส่ Google Maps API Key | **ไม่ต้องแก้ก็ได้** รายการร้านด้านล่างยังใช้ได้ปกติ วิธีขอคีย์อยู่ใน `docs/02_วิธีติดตั้งและรัน.txt` หัวข้อ 5 |
| รูปอาหาร/รูปร้านไม่ขึ้นบนมือถือ | ลืมแก้ `PUBLIC_BASE_URL` | กลับไปทำขั้น 5.3 แล้วรีสตาร์ท backend |
| หน้าแรกไม่มีของขายเลย | ข้อมูลทดลองหมดอายุแล้ว | Import `database\refresh_time.sql` เข้าฐาน `saveeats` เพื่อเลื่อนเวลาให้ทันสมัย |
| แก้โค้ดแล้วแอปไม่อัปเดต | Metro ใช้ไฟล์เก่าจากแคช | ปิดด้วย Ctrl+C แล้วเปิดใหม่ด้วย `npx expo start --clear` |
| `npm error code ERESOLVE` ตอน install | ไลบรารีชนกัน | ลบโฟลเดอร์ `node_modules` กับไฟล์ `package-lock.json` ในโฟลเดอร์นั้น แล้ว `npm install` ใหม่ |
| หน้า Admin ล็อกอินแล้วหมุนค้าง | backend ไม่ได้เปิด | เช็คหน้าต่าง cmd ที่ 1 ว่ายังทำงานอยู่ไหม |

## สรุปสิ่งที่ต้องเปิดค้างไว้ทุกครั้งที่ทดสอบ

1. XAMPP → **MySQL** (Apache เปิดด้วยถ้าจะเข้า phpMyAdmin)
2. cmd ที่ 1 → `npm run dev` ในโฟลเดอร์ `backend`
3. cmd ที่ 2 → `npx expo start` ในโฟลเดอร์ `mobile`
4. cmd ที่ 3 → `npm run dev` ในโฟลเดอร์ `admin-web` (เฉพาะตอนจะทดสอบหน้า Admin)

**ครั้งต่อ ๆ ไปไม่ต้องทำขั้น 0–5 ซ้ำ** เริ่มที่ขั้น 6 ได้เลย
ยกเว้นกรณีเดียวคือ**เปลี่ยน Wi-Fi หรือย้ายสถานที่** ต้องกลับไปแก้ IP ในขั้น 5 ใหม่

## ติดแล้วแก้ไม่ได้ ส่งข้อมูลนี้มาให้

1. รูปหน้าจอ cmd ที่ขึ้น error ทั้งหน้าต่าง (ไม่ใช่แค่บรรทัดสุดท้าย)
2. ทำถึงขั้นไหนแล้ว
3. ผลของคำสั่ง `node -v`
4. เลขพอร์ตที่เห็นในหน้า phpMyAdmin (ขั้น 3.3)
