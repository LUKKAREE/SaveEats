--------------------------------------------------------------------------------

  ================================================================
   ทำไมต้องโหลด Expo Go ด้วย  (คำถามที่ถูกถามบ่อยที่สุด)
  ================================================================

  [ปัญหาที่ Expo แก้ให้เรา]

  React Native เป็นแค่ตัวแปลงโค้ด React ให้กลายเป็นหน้าจอมือถือจริง
  แต่การจะเอาโค้ดขึ้นไปรันบนมือถือได้ ต้องมีเครื่องมือฝั่ง native อีกชุดใหญ่

      ฝั่ง Android ต้องมี
          Android Studio           ขนาดประมาณ 10 GB
          Android SDK + Build Tools
          JDK (Java Development Kit)
          Gradle
          ตั้งค่าตัวแปรระบบ ANDROID_HOME และ JAVA_HOME ให้ถูก

      ฝั่ง iOS ต้องมี
          เครื่อง Mac เท่านั้น
          Xcode  ขนาดประมาณ 15 GB
          CocoaPods

  *** ข้อสุดท้ายสำคัญมากสำหรับทีมเรา ***
  ถ้าไม่ใช้ Expo คนที่ใช้ Windows จะทดสอบบน iPhone ไม่ได้เลย ไม่มีทางอ้อม
  และเพื่อนในทีมทุกคนต้องติดตั้งของพวกนี้ให้ครบเหมือนกันหมด
  ซึ่งเป็นจุดที่โปรเจกต์นักศึกษาส่วนใหญ่ติดกันตรงนี้แล้วเสียเวลาเป็นวัน

  [Expo Go ทำงานยังไง]

  Expo Go คือ "แอปเปล่า" ที่ทีม Expo คอมไพล์มาให้แล้ว
  ข้างในมีโค้ด native ของ React Native และไลบรารียอดนิยมติดมาครบ
  (กล้อง GPS แผนที่ เลือกรูป ฯลฯ)

  ลำดับที่เกิดขึ้นตอนเรากด npm start

      1. คอมเรารวมโค้ด JavaScript ทั้งโปรเจกต์เป็นก้อนเดียว (เรียกว่า bundle)
      2. เปิดเซิร์ฟเวอร์เล็ก ๆ บนคอม แล้วโชว์ QR ให้สแกน
      3. Expo Go บนมือถือสแกน QR แล้วโหลด bundle นั้นมารัน
      4. เห็นแอปของเราทันที

  เท่ากับว่า Expo Go เป็น "ภาชนะ" ส่วนโค้ดเราเป็น "ของที่ใส่เข้าไป"

  ผลที่ได้
      ไม่ต้องคอมไพล์เอง
      ไม่ต้องสร้างไฟล์ APK
      ไม่ต้องต่อสาย USB
      แก้โค้ดแล้วบันทึก มือถืออัปเดตให้เองใน 1-2 วินาที

  [โปรเจกต์นี้ใช้ของ Expo ตรงไหนบ้าง]

  จากแพ็กเกจ 20 ตัวในโฟลเดอร์ mobile เป็นของ Expo 8 ตัว

      expo-camera               สแกน QR ตอนร้านรับอาหาร   (ใช้ 1 ไฟล์)
      expo-location             หาตำแหน่งเพื่อโชว์ระยะทาง (ใช้ 1 ไฟล์)
      expo-image-picker         เลือกรูปอาหารและรูปร้าน    (ใช้ 1 ไฟล์)
      @expo-google-fonts/prompt ฟอนต์ไทย                  (ใช้ 1 ไฟล์)
      @expo/vector-icons        ไอคอนทั้งแอป              (ใช้ 37 ไฟล์)
      expo, expo-font, expo-status-bar   ตัวหลักและของประกอบ

  อีก 12 ตัวไม่ใช่ของ Expo เลย เช่น react-navigation, react-native-maps,
  axios, async-storage ซึ่งใช้ได้เหมือนกันไม่ว่าจะมี Expo หรือไม่

  [ราคาที่ต้องจ่าย - ข้อเสียของ Expo ที่ควรรู้]

  1. ใช้ได้เฉพาะไลบรารีที่ Expo Go คอมไพล์มาให้
     ถ้าวันหนึ่งอยากใช้ native library แปลก ๆ ที่ไม่มีในนั้น
     ต้องเปลี่ยนไปใช้ EAS Build หรือ prebuild ซึ่งกลับไปยุ่งกว่าเดิม
     (ของที่โปรเจกต์เราใช้อยู่ตอนนี้มีครบใน Expo Go หมดแล้ว)

  2. ผูกกับรุ่นของ Expo SDK
     โปรเจกต์นี้ใช้ SDK 51 ตัวเลขเวอร์ชันของแพ็กเกจ expo-xxx
     ต้องเป็นรุ่นที่คู่กับ SDK 51 จะอัปเดตมั่วไม่ได้
     *** ถ้าจะอัปเกรด ให้ใช้คำสั่ง npx expo install แทน npm install ***
     เพราะมันจะเลือกเวอร์ชันที่เข้ากันให้เอง

  3. ไฟล์แอปตอน build จริงใหญ่กว่าเล็กน้อย
     ระดับที่ไม่มีผลกับการส่งงาน

  [เข้าใจผิดที่พบบ่อย]

  *** ผู้ใช้จริงไม่ต้องโหลด Expo Go ***
  Expo Go ใช้เฉพาะตอนพัฒนาเท่านั้น
  ตอนจะส่งขึ้น Play Store จริง เราจะ build เป็นไฟล์ APK หรือ AAB
  แล้วผู้ใช้ติดตั้งเหมือนแอปทั่วไป ไม่รู้ด้วยซ้ำว่าเราใช้ Expo

  [สรุปสั้นที่สุด]

  โหลด Expo Go 1 แอป  แลกกับการไม่ต้องติดตั้ง Android Studio 10 GB

================================================================================

1.1  เปิด XAMPP Control Panel
     - กดปุ่ม Start ตรงแถว Apache
     - กดปุ่ม Start ตรงแถว MySQL
     - ทั้งสองแถวต้องขึ้นพื้นเขียวและมีเลข Port

     ถ้ากด Start แล้วไม่ขึ้นเขียว -> ดูหัวข้อ "ปัญหาที่เจอบ่อย" ข้อ 1

1.2  เปิดเบราว์เซอร์ ไปที่
         http://localhost/phpmyadmin

1.3  Import ไฟล์ schema.sql
     - คลิกแท็บ "Import" ด้านบน
     - กด "Choose File" แล้วเลือกไฟล์  SaveEats/database/schema.sql
     - เลื่อนลงล่างสุด กดปุ่ม "Go" (หรือ "นำเข้า")
     - รอสักครู่ ต้องขึ้นข้อความสีเขียวว่าสำเร็จ

     *** ไฟล์นี้สร้างฐานข้อมูลชื่อ saveeats ให้เอง ไม่ต้องสร้างเองก่อน ***

1.4  Import ไฟล์ seed.sql (ข้อมูลทดลอง)
     - ดูเมนูซ้ายมือ จะเห็นฐานข้อมูล "saveeats" โผล่ขึ้นมาแล้ว **คลิกที่ชื่อมัน**
     - คลิกแท็บ "Import" อีกครั้ง
     - เลือกไฟล์  SaveEats/database/seed.sql
     - กด "Go"

     *** ต้องคลิกเลือกฐานข้อมูล saveeats ก่อน Import ไฟล์นี้ ***
     *** ถ้าไม่เลือก จะขึ้น error ว่า No database selected ***

1.5  ตรวจว่าสำเร็จ
     - คลิก saveeats ทางซ้าย
     - ต้องเห็นตาราง 11 ตาราง :
           behavior_logs, behavior_scores, categories, foods, notifications,
           posts, reports, reservations, reviews, stores, users
     - คลิกตาราง users ต้องเห็นข้อมูล 8 แถว

     ถ้าอยากล้างข้อมูลเริ่มใหม่ ให้ Import schema.sql ซ้ำได้เลย
     *** ระวัง : ข้อมูลเดิมจะหายหมด เพราะไฟล์มีคำสั่ง DROP DATABASE อยู่ ***

     package ที่ติดตั้ง
         typescript          ตัวภาษา TypeScript
         tsx (dev)           รันไฟล์ .ts ตรง ๆ โดยไม่ต้อง build ก่อน

     *** ไม่ใช้ nodemon แล้ว ***
     เพราะ tsx มีโหมด watch ในตัว (คำสั่ง npm run dev = tsx watch server.ts)
     แก้โค้ดแล้วรีสตาร์ทให้เองเหมือนกัน

     *** หมายเหตุ : ใช้ bcryptjs ไม่ใช่ bcrypt ***
     เพราะ bcrypt ตัวเดิมต้อง compile ตอนติดตั้ง บน Windows มักติดตั้งไม่ผ่าน
     ส่วน bcryptjs เป็น JavaScript ล้วน ใช้งานเหมือนกันทุกอย่าง

4.1  หาเลข IP ของคอมก่อน   *** ขั้นนี้สำคัญที่สุด ห้ามข้าม ***
--------------------------------------------------------------------------------

  ทำไมต้องหา IP
  -------------
      มือถือเรียก http://localhost:3000 ไม่ได้
      เพราะคำว่า localhost บนมือถือ หมายถึง "ตัวมือถือเอง" ไม่ใช่คอมของคุณ

      คอม     เข้าได้     http://localhost:3000
      มือถือ  เข้าไม่ได้  http://localhost:3000
      มือถือ  เข้าได้     http://192.168.1.35:3000   <- ต้องใช้แบบนี้

  วิธีหา IP บน Windows
  --------------------
      1. เปิด Command Prompt
      2. พิมพ์   ipconfig   แล้วกด Enter
      3. หาบรรทัดที่เขียนว่า  IPv4 Address
      4. จะได้เลขประมาณ  192.168.1.35  หรือ  192.168.0.101

      *** ถ้ามีหลายอัน ให้เลือกอันที่อยู่ใต้หัวข้อ
          "Wireless LAN adapter Wi-Fi" ***
      *** อย่าเอาเลขที่ขึ้นต้นด้วย 169.254 (แปลว่าเน็ตมีปัญหา) ***

4.7  ลองวงจรหลักให้ครบ 1 รอบ (แนะนำให้ทำเลย)
--------------------------------------------------------------------------------

  วงจรหลัก = ร้านลงขาย -> ลูกค้าจอง -> ร้านสแกน QR -> ปิดการจอง
  ตอนนี้ทำผ่านหน้าจอจริงได้ครบทุกขั้นแล้ว

  ขั้นที่ 1 : login เป็นร้าน (seller1@test.com)
      แท็บ "หน้าหลัก" -> ปุ่ม "จัดการเมนู" -> ปุ่ม "+" -> กรอกเมนูใหม่ + ใส่รูป
      แท็บ "หน้าหลัก" -> ปุ่ม "สร้างโพสต์ขาย" -> เลือกเมนูนั้น -> ตั้งราคาลด
                        -> เลือกช่วงเวลารับ -> กดสร้าง

  ขั้นที่ 2 : ออกจากระบบ แล้ว login เป็นลูกค้า (customer1@test.com)
      แท็บ "หน้าแรก" -> ดึงลงรีเฟรช -> จะเห็นโพสต์ที่ร้านเพิ่งลง
      กดที่การ์ด -> กด "จองเลย" -> เลือกจำนวน -> กดยืนยัน
      จะได้หน้า QR Code + รหัส 4 หลัก

  ขั้นที่ 3 : ออกจากระบบ แล้ว login เป็นร้านอีกครั้ง
      แท็บ "สแกน" (ปุ่มเขียวกลางล่าง) -> ส่องกล้องที่ QR ของลูกค้า
      หรือ ถ้าใช้ Emulator ที่กล้องใช้ไม่ได้
          กด "กรอกรหัสแทน" -> ใส่เลข 4 หลักที่ลูกค้าเห็น

  ขั้นที่ 4 : กลับไปเป็นลูกค้า -> แท็บ "การจอง"
      สถานะจะเปลี่ยนเป็น "รับอาหารแล้ว"

  *** ถ้าร้านยังลงขายไม่ได้ ให้เช็คสถานะร้านก่อน ***
  ร้านที่สถานะยัง "รอตรวจสอบ" จะสร้างโพสต์ไม่ได้ (Backend กันไว้)
  วิธีแก้ : เปิด Admin Web -> login admin@saveeats.com -> หน้า "อนุมัติร้านค้า"
           -> กดอนุมัติร้านนั้น

  ยังไม่ต้องใส่ก็ได้ ส่วนอื่นของแอปทำงานปกติ
  และรายการร้านที่อยู่ใต้แผนที่ก็ยังใช้งานได้ตามปกติ
  วิธีขอคีย์และวิธีใส่ อยู่ที่ขั้นที่ 5 ข้างล่างนี้

  *** ไม่ต้องโหลดฟอนต์เองแล้ว ***

5.1  ขอคีย์จาก Google   (ฟรี แต่ต้องผูกบัตร)
--------------------------------------------------------------------------------

  *** เรื่องเงินที่ต้องรู้ก่อน ***
  Google ให้เครดิตฟรีเดือนละ 200 ดอลลาร์สำหรับ Maps
  การใช้ระดับโปรเจกต์เรียนไม่มีทางถึงเพดานนั้น จึงไม่เสียเงินจริง
  แต่ Google บังคับให้ผูกบัตรก่อนถึงจะเปิดใช้ได้ ถ้าไม่สะดวกก็ข้ามขั้นนี้ไปเลย

  ขั้นตอน

  1. เปิด  https://console.cloud.google.com
     เข้าสู่ระบบด้วยบัญชี Google

  2. สร้างโปรเจกต์ใหม่
     - กดที่กล่องเลือกโปรเจกต์ด้านบนซ้าย (ข้าง ๆ คำว่า Google Cloud)
     - กด "New Project"
     - ตั้งชื่อว่า SaveEats แล้วกด Create
     - รอสักครู่แล้วเลือกโปรเจกต์ที่เพิ่งสร้าง

  3. เปิดใช้ Maps SDK for Android
     - ช่องค้นหาด้านบน พิมพ์ว่า  Maps SDK for Android
     - กดเข้าไปแล้วกดปุ่ม "Enable"
     - ถ้ายังไม่ได้ผูกบัตร ตรงนี้จะให้ผูกก่อน

  4. สร้างคีย์
     - เมนูซ้าย -> APIs & Services -> Credentials
     - กด "+ CREATE CREDENTIALS" ด้านบน -> เลือก "API key"
     - จะได้ข้อความยาว ๆ ขึ้นต้นด้วย AIza... นั่นคือคีย์ของเรา
     - กด "Copy" เก็บไว้

  5. *** จำกัดสิทธิ์ของคีย์ก่อนเอาไปใช้ (สำคัญมาก) ***
     ถ้าไม่จำกัด ใครได้คีย์ไปก็เอาไปใช้จนเราโดนเรียกเก็บเงินได้

     - กดที่ชื่อคีย์ที่เพิ่งสร้าง
     - หัวข้อ "API restrictions"
           เลือก "Restrict key" แล้วติ๊กเฉพาะ  Maps SDK for Android
     - หัวข้อ "Application restrictions"
           ตอนพัฒนาด้วย Expo Go ให้เลือก "None" ไปก่อน
           (เพราะ Expo Go ใช้ลายเซ็นแอปของ Expo ไม่ใช่ของเรา)
           ตอนจะ build เป็นไฟล์จริงค่อยเปลี่ยนเป็น "Android apps"
           แล้วใส่ package name = com.saveeats.app กับลายนิ้วมือ SHA-1
     - กด Save

5.3  ทำไมต้องใส่ใน .env ไม่ใส่ใน app.json ตรง ๆ
--------------------------------------------------------------------------------

  เพราะคีย์เป็นความลับ ถ้าใส่ใน app.json แล้ว commit ขึ้น GitHub
  ใครก็เอาคีย์เราไปใช้ได้ และบิลจะมาที่เรา

  โครงสร้างที่ตั้งไว้ให้แล้ว
      mobile/app.json         ค่าตั้งทั่วไป  -> ขึ้น git ได้
      mobile/.env             คีย์ลับ        -> อยู่ใน .gitignore แล้ว
      mobile/.env.example     ตัวอย่างเปล่า  -> ขึ้น git ได้ ให้เพื่อนรู้ว่าต้องใส่อะไร
      mobile/app.config.ts    ตัวเอาสองอันมารวมกันตอนเปิดแอป

  *** เพื่อนในทีมแต่ละคนต้องสร้าง .env ของตัวเอง ***
  เพราะไฟล์นี้ไม่ขึ้น git จะใช้คีย์เดียวกันทั้งทีมก็ได้
  แค่ส่งคีย์ให้กันทางช่องทางอื่น อย่าส่งผ่าน commit

  ถ้าเปิดแอปแล้วขึ้นข้อความเตือนสีเหลืองว่ายังไม่ได้ใส่คีย์
  แปลว่าไฟล์ .env ยังไม่มี หรือชื่อตัวแปรพิมพ์ผิด

--------------------------------------------------------------------------------
ปัญหา 1 : กด Start MySQL ใน XAMPP แล้วไม่ขึ้นสีเขียว
--------------------------------------------------------------------------------
  สาเหตุที่พบบ่อยที่สุด : มีโปรแกรมอื่นใช้ Port 3306 อยู่แล้ว
  มักเป็นเพราะเคยติดตั้ง MySQL แยกไว้ต่างหาก

  วิธีแก้ที่ 1 (แนะนำ) : ปิด MySQL ตัวเดิม
      1. กด Windows + R พิมพ์  services.msc  กด Enter
      2. หาบรรทัดที่ชื่อขึ้นต้นด้วย MySQL
      3. คลิกขวา -> Stop
      4. คลิกขวา -> Properties -> Startup type เลือก Manual -> OK
      5. กลับไปกด Start ใน XAMPP ใหม่

  วิธีแก้ที่ 2 : เปลี่ยน Port ของ XAMPP
      1. ใน XAMPP กด Config ตรงแถว MySQL -> my.ini
      2. หาบรรทัด  port=3306  เปลี่ยนเป็น  port=3307
      3. บันทึก แล้วกด Start ใหม่
      4. *** ต้องไปแก้ backend/.env ให้เป็น DB_PORT=3307 ด้วย ***

--------------------------------------------------------------------------------
  ไล่เช็คตามลำดับนี้

  [ ] เปิด MySQL ใน XAMPP แล้วหรือยัง (ต้องเป็นสีเขียว)
  [ ] Import schema.sql เข้า phpMyAdmin แล้วหรือยัง
  [ ] มีไฟล์ .env ในโฟลเดอร์ backend หรือยัง (ไม่ใช่แค่ .env.example)

ปัญหา 11 : Import schema.sql แล้วขึ้นแดง หรือได้ตารางไม่ครบ 11 ตาราง
--------------------------------------------------------------------------------
  phpMyAdmin จะ "หยุดทันที" เมื่อเจอคำสั่งแรกที่ผิด
  คำสั่งที่เหลือหลังจากนั้นจะไม่ถูกรันเลย
  ทำให้ได้ตารางไม่ครบ แล้ว seed.sql ก็จะพังตามไปด้วย
  (ขึ้นว่า Table 'saveeats.xxx' doesn't exist)

  วิธีตรวจ
      คลิก saveeats ทางซ้ายมือ แล้วนับตาราง ต้องมีครบ 11 ตาราง
          behavior_logs, behavior_scores, categories, foods, notifications,
          posts, reports, reservations, reviews, stores, users

  ถ้าไม่ครบ ให้ดูว่าตารางสุดท้ายที่สร้างได้คือตารางไหน
  ปัญหาจะอยู่ที่ตารางถัดจากนั้น

  *** สาเหตุที่พบบ่อยที่สุด : ตั้งชื่อคอลัมน์ตรงกับคำสงวนของ MySQL ***
  เช่น  change, order, group, key, read, range, rank, interval, condition
  ถ้าจำเป็นต้องใช้จริง ๆ ต้องครอบด้วย backtick แบบนี้ `change`
  แต่ทางที่ดีกว่าคือเปลี่ยนชื่อไปเลย (เช่น เปลี่ยน change เป็น score_change)

  วิธีแก้เมื่อแก้ schema.sql เสร็จแล้ว
      1. Import schema.sql ใหม่อีกครั้ง (ไฟล์มี DROP DATABASE อยู่แล้ว ล้างให้เอง)
      2. คลิกฐานข้อมูล saveeats ทางซ้าย
      3. Import seed.sql ตามไป

  *** อีกสาเหตุที่เจอบ่อย : ใช้ TRUNCATE TABLE กับตารางที่มี Foreign Key ***
  จะขึ้น error
      #1701 - Cannot truncate a table referenced in a foreign key constraint

  MariaDB ที่มากับ XAMPP ไม่ยอมให้ TRUNCATE ตารางที่มีตารางอื่นอ้างถึง
  ถึงจะสั่ง SET FOREIGN_KEY_CHECKS = 0 ไว้แล้วก็ตาม (ต่างจาก MySQL)

  วิธีแก้ : ใช้ DELETE FROM แทน แล้วตามด้วย ALTER TABLE ... AUTO_INCREMENT = 1
  (seed.sql ของเราแก้ให้แล้ว ดูตัวอย่างได้ที่หัวไฟล์)

ปัญหา 12 : MySQL ของ XAMPP ไม่ได้อยู่ที่ port 3306
--------------------------------------------------------------------------------
  ดูที่หัวหน้าจอ phpMyAdmin จะเขียนว่า  Server: 127.0.0.1:3307

      DB_PORT=3307

  ไม่งั้น Backend จะขึ้นว่า "เชื่อมต่อฐานข้อมูลไม่สำเร็จ"
  ทั้งที่ phpMyAdmin เปิดได้ปกติ

      npx expo start -c

  *** อย่าย้ายโฟลเดอร์ shared/ ออกจากระดับเดียวกับ backend/ mobile/ admin-web/ ***
  เพราะทางลัดทั้งหมดชี้ไปที่ ../shared/src
