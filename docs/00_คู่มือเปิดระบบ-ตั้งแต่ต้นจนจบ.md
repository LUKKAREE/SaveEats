# คู่มือเปิดระบบ SaveEats ตั้งแต่ต้นจนจบ

เอกสารนี้ใช้ทุกครั้งที่เปิดเครื่องมาทำงาน หรือวันสาธิตให้อาจารย์ดู
ทำตามลำดับ 1 → 6 ห้ามข้าม

---

## ภาพรวม : ต้องเปิดค้างไว้ 4 อย่าง

| # | หน้าต่าง | รันอะไร | พอร์ต |
|---|---|---|---|
| 1 | XAMPP | MySQL | 3306 |
| 2 | cmd หน้าต่างที่ 1 | backend | 3000 |
| 3 | cmd หน้าต่างที่ 2 | admin-web | 5173 |
| 4 | cmd หน้าต่างที่ 3 | mobile (Expo) | 8081 |

**ปิดอันไหนอันหนึ่ง ตัวที่เหลือพังตามกันหมด**

## ขั้นที่ 2 — เปิดฮอตสปอตและเช็ค IP

1. เปิดฮอตสปอตที่มือถือ
2. ให้คอมต่อเข้าฮอตสปอตนั้น
3. เปิด cmd แล้วพิมพ์ (รันจากโฟลเดอร์ไหนก็ได้)

```
ipconfig
```

4. เลื่อนหาหัวข้อ **`Wireless LAN adapter Wi-Fi:`** แล้วดูบรรทัด **IPv4 Address**

**ห้ามใช้เลขจากหัวข้ออื่น** โดยเฉพาะ
- `Radmin VPN` (ขึ้นต้น 26.x)
- `vEthernet` / `WSL` (ขึ้นต้น 172.x)

### ถ้าเลขเป็น 10.84.100.33

ผ่าน ข้ามไปขั้นที่ 3 ได้เลย

### ถ้าเลขเปลี่ยน

เปิดไฟล์ `mobile\src\core\constants\apiConstants.ts`
หาบรรทัดที่ 25 แล้วแก้เลขให้ตรง

```ts
const DEV_HOST = '10.84.100.33';   // <-- แก้ตรงนี้
```

บันทึกไฟล์ (Ctrl+S)

## ขั้นที่ 5 — เช็คว่ามือถือคุยกับ Backend ได้

**ทำขั้นนี้ก่อนเปิดแอปเสมอ จะประหยัดเวลามาก**

เปิดเบราว์เซอร์ **บนมือถือ** พิมพ์ในช่องที่อยู่ด้านบนสุด (ไม่ใช่ช่องค้นหา Google)

```
10.84.100.33:3000/api/health
```

**ระวัง** : ระหว่าง `33` กับ `3000` เป็นเครื่องหมาย **โคลอน `:`** (จุดสองจุดเรียงแนวตั้ง) ไม่ใช่จุด `.`

วิธีพิมพ์โคลอนบนคีย์บอร์ดมือถือ : กด `?123` แล้วหาปุ่ม `:`
ถ้าไม่เจอให้กด `=\<` เพื่อไปหน้าสัญลักษณ์ชุดที่ 2

- [ ] เห็น `{"success":true,"message":"SaveEats API ทำงานปกติ",...}`

### ถ้าเข้าไม่ได้

| อาการ | แก้ยังไง |
|---|---|
| เด้งไปหน้าค้นหา Google | พิมพ์ URL ผิด ดูเรื่องโคลอนด้านบน |
| "ไซต์นี้เข้าถึงไม่ได้" | มือถือกับคอมไม่ได้อยู่วงเดียวกัน หรือ Firewall บล็อก |
| ค้างโหลดนาน | backend ในขั้นที่ 3 ปิดไปแล้ว |

วิธีเช็ค Firewall : ปิด Windows Firewall ชั่วคราวแล้วลองใหม่
ถ้าปิดแล้วเข้าได้ = Firewall บล็อกจริง ให้เปิดกลับแล้วกด **Allow** ตอนที่มันเด้งถาม

## ถ้าขั้นที่ 6 เด้งกลับ prompt ทันที ไม่มี QR

ไล่ตามลำดับนี้ หยุดเมื่อขั้นไหนใช้ได้

### 6.1 ปิด Radmin VPN แล้วลองใหม่

คลิกขวาไอคอนใน system tray → Exit → รัน `npx expo start --clear` อีกครั้ง

### 6.2 ลองโหมดออฟไลน์

```
npx expo start --offline
```

ถ้าอันนี้ขึ้น QR ได้ = ปัญหาอยู่ที่ Expo ต่อเน็ตไปเช็คเวอร์ชันแล้วพัง
ใช้คำสั่งนี้ไปเลยก็ได้ ทำงานได้ปกติทุกอย่าง

### 6.3 ลองพอร์ตอื่น

```
npx expo start --port 8082
```

เผื่อมีโปรแกรมอื่นยึดพอร์ต 8081 อยู่

### 6.4 เก็บ log ส่งให้ช่วยดู

```
set EXPO_DEBUG=1
npx expo start --clear > expo-log.txt 2>&1
```

รอ 30 วินาที แล้วเปิดไฟล์ `mobile\expo-log.txt` ดู error ข้างใน

## ข้อความที่เห็นแล้วไม่ต้องตกใจ

| ข้อความ | หมายความว่า |
|---|---|
| `[SaveEats] ยังไม่ได้ใส่ GOOGLE_MAPS_API_KEY` | ปกติ หน้าแผนที่จะเป็นจอเทาเท่านั้น ส่วนอื่นใช้ได้ครบ |
| `npm warn deprecated ...` | ไลบรารีเก่าที่ Expo ดึงมาเอง ไม่กระทบการทำงาน |
| `16 vulnerabilities (7 moderate, 9 high)` | อยู่ใน build tool ไม่ได้ติดไปกับแอป โปรเจค React Native ทุกตัวขึ้นแบบนี้ |
| `GET / 404` ที่หน้าต่าง backend | ถูกต้อง backend เป็น API ล้วน ไม่มีหน้าเว็บ |
| `GET /favicon.ico 404` | เบราว์เซอร์ขอไอคอนแท็บเอง ไม่เกี่ยวอะไร |

### ห้ามทำเด็ดขาด

```
npm audit fix --force
```

คำสั่งนี้จะเปลี่ยนเวอร์ชัน `react-native` / `expo-*` ให้หลุดจากที่ Expo Go SDK 54 รองรับ แล้วแอปจะพังทันที
