2.2  Import ฐานข้อมูล (ทำครั้งแรกครั้งเดียว)
--------------------------------------------------------------------------------
  เปิด http://localhost/phpmyadmin

  ก) Import โครงสร้าง
     - แท็บ Import -> Choose File -> database/schema.sql -> Go
     - ต้องขึ้นเขียว และเห็นฐานข้อมูล saveeats โผล่ทางซ้าย

  ข) Import ข้อมูลทดลอง
     - *** คลิกที่ชื่อ saveeats ทางซ้ายก่อน *** (สำคัญมาก)
     - แท็บ Import -> Choose File -> database/seed.sql -> Go

     *** ถ้าคลิกที่ชื่อ "ตาราง" แทนที่จะคลิกชื่อ "ฐานข้อมูล" ***
     phpMyAdmin จะ import เข้าตารางเดียว แล้วข้อมูลจะไม่ครบ

--------------------------------------------------------------------------------
2.3  เลื่อนเวลาข้อมูลทดลอง  *** ทำทุกครั้งที่จะเริ่มทดสอบ ***
--------------------------------------------------------------------------------
  ข้อมูลใน seed.sql ตั้งเวลารับอาหารไว้ 17:00-20:00 ของวันที่ import
  ถ้าทดสอบคนละวัน หรือทดสอบหลัง 20:00
  *** Feed จะว่างเปล่า เพราะระบบกรองโพสต์ที่เลยเวลารับออกหมด ***

  วิธีแก้ ใช้เวลา 10 วินาที
     - คลิก saveeats ทางซ้าย -> แท็บ Import
     - เลือกไฟล์ database/refresh_time.sql -> Go

  ไฟล์นี้เลื่อนเวลาให้เริ่มจากตอนนี้ไปอีก 6 ชั่วโมง ไม่ลบข้อมูล ใช้ซ้ำได้เรื่อย ๆ

ขั้นที่ 5 : ต่อมือถือเข้ากับ Backend
================================================================================
*** ขั้นนี้คนติดมากที่สุด อ่านช้า ๆ ***

--------------------------------------------------------------------------------
5.1  ทำไมต้องตั้งค่า IP
--------------------------------------------------------------------------------
  คำว่า localhost บนมือถือ หมายถึง "ตัวมือถือเอง" ไม่ใช่คอมของเรา
  ถ้าปล่อยไว้ มือถือจะหา Backend ไม่เจอ

  ต้องบอกมือถือว่า Backend อยู่ที่ IP ของคอมในวง Wi-Fi

--------------------------------------------------------------------------------
5.2  หาเลข IP ของคอม
--------------------------------------------------------------------------------
  เปิด Command Prompt แล้วพิมพ์

      ipconfig

  หาบรรทัดที่เขียนว่า  IPv4 Address
  จะได้เลขประมาณ  192.168.1.35  หรือ  192.168.10.83

  *** ถ้ามีหลายอัน ให้เลือกอันที่อยู่ใต้หัวข้อ ***
      Wireless LAN adapter Wi-Fi        <- ถ้าต่อ Wi-Fi
      Ethernet adapter Ethernet         <- ถ้าต่อสาย LAN

  *** อย่าเอาเลขที่ขึ้นต้นด้วย 172.x หรือ 26.x ***
  พวกนั้นมักเป็นของ WSL, Docker, VirtualBox หรือ VPN ไม่ใช่ Wi-Fi จริง

--------------------------------------------------------------------------------
5.3  เอา IP ไปใส่ในโค้ด
--------------------------------------------------------------------------------
  เปิดไฟล์

      mobile/src/core/constants/apiConstants.ts

  หาบรรทัดที่เขียนว่า

      const DEV_HOST = '192.168.1.35';

  แก้เลขให้เป็นของคอมเรา แล้วบันทึก

  *** IP เปลี่ยนทุกครั้งที่ย้ายที่หรือเปลี่ยน Wi-Fi ต้องกลับมาแก้ใหม่ ***
  เช่น ทำที่บ้านกับที่มหาลัยจะคนละเลข

--------------------------------------------------------------------------------
5.4  ทดสอบก่อนว่ามือถือเข้า Backend ได้จริง
--------------------------------------------------------------------------------
  *** ทำขั้นนี้ก่อนเปิดแอป จะประหยัดเวลามาก ***

  เปิดเบราว์เซอร์ "บนมือถือ" แล้วพิมพ์

      http://192.168.1.35:3000/api/health      (แก้เลขเป็นของคุณ)

  [ ] เห็นข้อความ JSON

  ถ้าเห็น = ผ่าน ไปขั้นต่อไปได้
  ถ้าไม่เห็น = ยังไม่ต้องเปิดแอป ให้แก้ตามนี้ก่อน

--------------------------------------------------------------------------------
10.3  คำถามที่อาจารย์มักถาม และคำตอบ
--------------------------------------------------------------------------------
  ถาม : QR ปลอมได้ไหม
  ตอบ : ไม่ได้ เพราะแอปไม่ได้เป็นคนตัดสินว่า QR ถูกหรือผิด
        ทุกครั้งที่สแกน จะส่งไปให้ Backend ตรวจ 5 ด่าน
        (มีจริงไหม / เป็นของร้านนี้ไหม / ใช้ไปแล้วยัง / หมดเวลาหรือยัง / ยกเลิกไปหรือยัง)

  ถาม : ถ้าคนกดจองพร้อมกันจนเกินของที่มี
  ตอบ : กันไว้ที่ระดับฐานข้อมูล ใช้คำสั่ง UPDATE ที่มีเงื่อนไข
        "ตัดของก็ต่อเมื่อยังเหลือพอ" อยู่ในคำสั่งเดียวกัน
        คนที่มาทีหลังจะตัดไม่สำเร็จและได้รับแจ้งว่าของหมด

  ถาม : ทำไมไม่มีระบบจ่ายเงินในแอป
  ตอบ : ตั้งใจไม่ทำ เพราะโจทย์คือให้มารับที่ร้านและจ่ายเงินสด
        การใส่ระบบจ่ายเงินจะเพิ่มความซับซ้อนโดยไม่ตอบโจทย์

  ถาม : ข้อมูลปลอดภัยแค่ไหน
  ตอบ : รหัสผ่านเก็บเป็น bcrypt hash ไม่ได้เก็บตัวจริง
        API ทุกเส้นที่ต้องใช้สิทธิ์ตรวจที่ Backend ไม่ได้ตรวจแค่ที่หน้าจอ
        และแอปกับเว็บไม่ได้ต่อฐานข้อมูลตรง ต้องผ่าน API เสมอ


================================================================================
 สรุปคำสั่งที่ใช้ทุกครั้ง
================================================================================

  1. เปิด XAMPP -> Start MySQL

  2. หน้าต่างที่ 1
         cd SaveEats\backend
         npm run dev

  3. หน้าต่างที่ 2
         cd SaveEats\admin-web
         npm run dev
         -> เปิด http://localhost:5173

  4. หน้าต่างที่ 3
         cd SaveEats\mobile
         npm start
         -> สแกน QR ด้วย Expo Go

  5. ถ้า Feed ว่าง -> import database/refresh_time.sql
  6. ถ้า login ไม่ผ่าน -> cd SaveEats\backend แล้ว npm run check-db
